# Assets Needed

This package intentionally contains no invented or substitute production imagery.

## Hoodie rotation

A production-quality scroll rotation requires 36 approved, consistently rendered frames:

- Clockwise front-to-back-to-front rotation.
- Transparent WebP or AVIF delivery files.
- Consistent square canvas; ideally 1800×1800 or larger source masters.
- Identical camera position, lighting, garment scale, and background.
- Clearly visible chest, sleeves, sides, and back.
- Predictable names: `hoodie-rotation-01.webp` through `hoodie-rotation-36.webp`.
- Optimised delivery size, ideally about 80–180 KB per frame.
- High-resolution masters retained separately.

Until these exist, use the approved static hero reference only as a visual specification. Do not extract its hoodie as a production asset and do not imply that one image provides real 360-degree rotation.
